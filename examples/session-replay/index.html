⚡ Zero Performance Impact Architecture: Lazy & Idle Loading in Production

In production web apps, @askdepth/replay is never loaded eagerly. The lightweight core (~3 KB) boots immediately, while the recording engine (~30 KB gzip) is dynamically imported strictly via requestIdleCallback after window.load (+3s delay). If the user's connection is slow or the site uses heavy libraries (like Framer Motion, Three.js, or complex hydration), Askdepth never competes for CPU or network resources, guaranteeing zero degradation to Core Web Vitals (LCP, INP, TBT). It only preempts on early frustration heuristics (e.g. 2 rapid clicks).
